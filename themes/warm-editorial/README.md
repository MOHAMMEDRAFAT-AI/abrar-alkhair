# مؤسسة أبرار الخير للإغاثة الإنسانية — الموقع الرسمي

موقع باللغة العربية RTL — يعمل بدون سيرفر، طلبات الكفالة تُحفظ في `localStorage`.
الشعار والصور حقيقية من المؤسسة في مجلد `assets/`. عدد الكفالات السارية: **250**.

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو:
```powershell
python -m http.server 8000
```

## التشغيل
1. افتح ملف `index.html` في المتصفح مباشرة (دبل كلك)، أو:
```powershell
npx serve .
# أو
python -m http.server 8000
```
ثم افتح `http://localhost:8000`

## الحسابات
| النوع | الدخول |
|---|---|
| 🛡️ المدير | المستخدم: `admin` — كلمة المرور: `admin123` (زر **دخول المدير** في الهيدر) |
| 🌙 اليتيم | يُنشأ **تلقائياً** بعد تعبئة فورم الكفالة — الدخول بـ **رقم الهوية + تاريخ الميلاد** ككلمة مرور |

## الدورة
1. من قسم **كفالة يتيم** اضغط «تسجيل يتيم جديد» → ينسدل الفورم (14 حقلاً) → إرسال.
2. تظهر بطاقة نجاح فيها بيانات الدخول + الحالة **قيد المراجعة ⏳**.
3. ادخل كمدير → لوحة المدير تعرض الطلب → **قبول ✓ / رفض ✕ / إرجاع للمراجعة** + بحث + فلترة + عرض التفاصيل + تصدير CSV + حذف.
4. ادخل كيتيم → لوحة اليتيم تعرض البيانات + **الحالة والخط الزمني** + زر استفسار واتساب.

## الأقسام (مشروع واحد: كفالة اليتيم — 250 كفالة سارية)
- هيدر: الشعار الرسمي **في الوسط** + تنقل + دخول — شريط علوي: فلسطين قطاع غزة
- هيرو: سلوجان «عطاءٌ يصنع الحياة» + آية + فيديو + عدّاد الكفالات الرسمي
- جدار المشاريع: شريط يعرض أسماء المشاريع تلقائياً (حلقة seamless)
- معرض المشاريع: كل مشروع له سلايدر بعدد غير محدود من الصور + تبويبات + موجات parallax + إمالة 3D + سوايب لمس
- لوحة المدير: إدارة المشاريع (إضافة/حذف) ورفع صور من الجهاز (تُصغَّر تلقائياً) — تظهر فوراً في الموقع
- المساهمة: زر **WA.ME** واتساب (`+970 597 364 752`) للتواصل المباشر حول الكفالة
- الفوتر: منصات التواصل + العنوان **فلسطين - قطاع غزة** + كلمة ضخمة مفرّغة

## الستايل المعتمد: التحريري الورقي الدافئ (warm-editorial)
ورقي + حبر + طيني + ظلال صلبة + إطار فيلم — نسخة أرشيفية مطابقة في `themes/warm-editorial/`.

## الملفات
```
index.html   — كل الواجهات (رئيسية + لوحة مدير + لوحة يتيم + مودال دخول)
css/style.css — تصميم عصري مستلهم من 21st.dev (زجاجي + توهجات + حركات هادئة)
js/app.js    — المنطق: سلايدر + فورم + دخول + لوحات + localStorage
```

## ملاحظات
- الصور والشعار حقيقية من المؤسسة (`assets/`) — فيديو الهيرو فقط من مكتبة خارجية مؤقتاً.
- لنقل حقيقي لاحقاً: يُستبدل `localStorage` بقاعدة بيانات (Supabase/Firebase) + يُرفع الفيديو والشعار الحقيقي.
