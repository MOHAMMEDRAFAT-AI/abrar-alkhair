# مؤسسة أبرار الخير للإغاثة الإنسانية — الموقع الرسمي

موقع باللغة العربية RTL — يعمل بدون سيرفر، طلبات الكفالة تُحفظ في `localStorage`.
الشعار والصور حقيقية من المؤسسة في مجلد `assets/`. عدد الكفالات السارية: **250**.

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو:
```powershell
python -m http.server 8000
```

## التشغيل
1. افتح ملف `index.html` في المتصفح مباشرة (دبل كلك)، أو:
```powershell
npx serve .
# أو
python -m http.server 8000
```
ثم افتح `http://localhost:8000`

## الحسابات
| النوع | الدخول |
|---|---|
| 🛡️ المدير | **وضع Supabase:** بالبريد وكلمة المرور المنشأة من لوحة Supabase ‏(Authentication) — **الوضع المحلي:** `admin / admin123` |
| 🌙 اليتيم | يُنشأ **تلقائياً** بعد الفورم — الدخول بـ **رقم الهوية + تاريخ الميلاد** |

## الربط بـ Supabase (للحفظ الحقيقي بدل المتصفح)
بدون مفاتيح يعمل الموقع **محلياً** (localStorage للتجربة). للتفعيل:
1. أنشئ مشروعاً مجانياً في [supabase.com](https://supabase.com) وانسخ **Project URL** و**anon key**
2. الصق كامل ملف `supabase/schema.sql` في **SQL Editor** ← Run (ينشئ الجداول والصلاحيات والتخزين وبيانات البداية)
3. من **Authentication** ← Add user ← أنشئ حساب المدير (بريد + كلمة مرور)
4. الصق القيم في أعلى `js/app.js`: `SUPABASE_URL` و`SUPABASE_ANON_KEY` — وارفع الموقع

## إضافة مدير ثانٍ (من لوحة المدير)
1. من **Authentication > Settings** عطّل **Enable email signups** (حتى لا يسجل أحد بنفسه)
2. انشر الدالة من جهازك (مرة واحدة):
```powershell
npx supabase login
npx supabase link --project-ref irwmxhkqoueqmmikwjye
npx supabase functions deploy create-admin
```
3. من لوحة المدير ← **إدارة المدراء** ← أدخل البريد وكلمة المرور ← إضافة — والمدير الجديد يدخل بنفس النافذة.
> القبول = تسجيل الطلب لدينا، وعند توفر الدعم يُرشَّح الاسم للكفالة (وليس كفالة سارية فوراً).

## الدورة
1. من قسم **كفالة يتيم** اضغط «تسجيل يتيم جديد» → ينسدل الفورم (14 حقلاً) → إرسال.
2. تظهر بطاقة نجاح فيها بيانات الدخول + الحالة **قيد المراجعة ⏳**.
3. ادخل كمدير → لوحة المدير تعرض الطلب → **قبول ✓ / رفض ✕ / إرجاع للمراجعة** + بحث + فلترة + عرض التفاصيل + تصدير CSV + حذف.
4. ادخل كيتيم → لوحة اليتيم تعرض البيانات + **الحالة والخط الزمني** + زر استفسار واتساب.

## الأقسام (مشروع واحد: كفالة اليتيم — 250 كفالة سارية)
- هيدر: الشعار الرسمي **في الوسط** + تنقل + دخول — شريط علوي: فلسطين قطاع غزة
- هيرو: سلوجان «عطاءٌ يصنع الحياة» + آية + شريط صور منحني متحرك (TiltedGrid) + عدّاد الكفالات الرسمي (250)
- جدار المشاريع: شريط يعرض أسماء المشاريع تلقائياً (حلقة seamless)
- معرض المشاريع: كل مشروع له سلايدر بعدد غير محدود من الصور (حالياً 18 صورة ميدانية) + تبويبات + موجات parallax + إمالة 3D + سوايب لمس
- لوحة المدير: إدارة المشاريع (إضافة/حذف) ورفع صور من الجهاز (تُصغَّر تلقائياً) — تظهر فوراً في الموقع
- المساهمة: زر **WA.ME** واتساب (`+970 597 364 752`) للتواصل المباشر حول الكفالة
- الفوتر: منصات التواصل + العنوان **فلسطين - قطاع غزة** + كلمة ضخمة مفرّغة
